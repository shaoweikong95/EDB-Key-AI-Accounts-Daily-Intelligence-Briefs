# EDB Key AI Accounts Daily Intelligence Briefs

Production source for the daily AI account intelligence dashboard.

- `index.html`: dashboard layout and rendering logic
- `data-core.js`: World/APAC, overview, account list and sources
- `news-1.js` ... `news-5.js`: account-news data grouped by AI category
- `categories.js`: primary AI-category grouping

Netlify should publish the repository root. The production URL is intended to remain stable while the data files refresh each day.
